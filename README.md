# 🎁 CaseFarm Stats

Статистика фарма кейсов - приложение для отслеживания выбитых кейсов, скинов и затрат.

## 🚀 Запуск

### Вариант 1: NW.js (рекомендуется, с файловым сохранением)
1. Скачайте NW.js SDK с [официального сайта](https://nwjs.io/downloads/)
2. Распакуйте в папку с приложением
3. Запустите `nw.exe`

### Вариант 2: Браузер
1. Просто откройте `index.html` в браузере
2. Используйте кнопку "Экспорт данных" для бэкапов

## 📊 Возможности

- ✅ Добавление кейсов с выбором цвета
- ✅ Добавление бесплатных скинов
- ✅ Учет затрат на аккаунты и панели
- ✅ Сохранение недельной статистики
- ✅ Просмотр истории по неделям и месяцам
- ✅ Темная/светлая тема
- ✅ Визуализация данных (диаграммы)
- ✅ Экспорт/импорт данных (JSON)
- ✅ Автоматическое сохранение цветов кейсов

## 💾 Сохранение данных

- **NW.js режим**: данные сохраняются в файл `data/farm_data.json`
- **Браузерный режим**: данные сохраняются в localStorage

## 🖥️ Системные требования

- Windows 7/8/10/11
- Любой современный браузер (Chrome, Edge, Firefox)
